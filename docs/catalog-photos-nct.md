# Фото из Национального каталога товаров (НКТ): права, поиск, результат

Полный проход по каталогу SALAMAT (`public.pharmacy_products`) с поиском карточек в НКТ (https://nct.gov.kz/#/catalog/1).
Итоговые числа — в `docs/catalog-photos-nct-results.md`, манифест — в `data/nct/`. Рабочие файлы (полный манифест кандидатов,
список правообладателей, журнал) — в `.photo-work/nct/`, в репозиторий не попадают.

## 1. Можно ли SALAMAT использовать фото из НКТ на своём сайте

**Нет, без письменного согласия правообладателя конкретного фото.** Общего разрешения не найдено ни в одном первичном
источнике. Проверено 18.11.2026:

| Источник | Что сказано | Вывод |
|---|---|---|
| Пользовательское соглашение НКТ («Соглашение об использовании информационной системы ЭКТ»), отдаётся сайтом по `https://nct.gov.kz/api/auth/users/user_terms/` (PDF) | Владелец — Министерство финансов РК, администратор — АО «Центр электронных финансов» (п. 1.2, 1.4). Пользователь отвечает за правомерность размещения и использования материалов (п. 7.1). Владелец и администратор не отвечают за нарушение пользователями авторских прав (п. 7.4). Претензии третьих лиц пользователь урегулирует сам (п. 8.5). Никакой лицензии на повторное использование материалов нет | Права на фото остаются у тех, кто их загрузил; оператор их не передаёт |

Свободное использование возможно только в случаях ст. 18–26: личные цели, цитирование, обучение, суд и т. п. Коммерческий каталог туда не входит | Нужен договор или письменное разрешение правообладателя |

Кто может дать разрешение:

* **Производитель или импортёр, зарегистрировавший карточку**, — основной правообладатель фото упаковки. В карточке НКТ
  указан производитель, иногда его БИН. Список по производителям: `.photo-work/nct/permission-requests.csv`. Проще всего
  запрашивать через поставщиков SALAMAT: дистрибьюторы обычно имеют от производителей пакеты фото для розничных сайтов.
* **АО «Казахтелеком»** (Единый оператор маркировки и прослеживаемости; постановление Правительства РК от 03.03.2020 № 95) —
  по карточкам, которые он сам собрал для товаров, выпущенных до 01.01.2026 (п. 5 пп. 3 Правил). У таких карточек лекарств
  поле `source` = 5, а фото названы по кодам вида `YM…`. Нужно уточнить у оператора, кому принадлежат права на эти фото.
* **Оператор НКТ** — АО «Центр электронных финансов» (ecc.kz). Контакты с сайта nct.gov.kz: Единый контакт-центр МФ РК
  +7 (7172) 73 55 15, +7 705 956 53 88, ecatalog@ecc.kz, Telegram-бот FinQoldau_bot. Оператор может подтвердить, кто загрузил
  фото и есть ли у него самого права, но сам по соглашению прав на фото поставщиков не передаёт.

Шаблон запроса — раздел 6. Пока разрешение не получено, **фото НКТ не скачиваются и не публикуются**. В манифесте
сохраняются только ссылки на карточки и изображения.

## 2. Что доступно через публичный API НКТ

Проверено по коду публичного сайта и пробными запросами, без авторизации и без обхода ограничений:

* `POST https://nct.gov.kz/api/core/products/search/?limit=48&offset=…` с телом `{"q": "…"}` — поиск. Все слова запроса
  должны совпасть (логика «И»), поле GTIN тоже участвует. Поэтому «слово + GTIN» (например, `Аспиратор 38023682`)
  находит именно карточки с этим штрихкодом. Сервер отдаёт не больше 48 карточек на страницу.
* Запрос из **одного** штрихкода вызывает ошибку сервера (HTTP 500 примерно через 30 с) — такие запросы конвейер не
  отправляет. `GET /api/core/tin/by-xtin/?xtin=` отвечает «xtin not found» даже для существующих кодов.
* `GET https://nct.gov.kz/api/core/products/{id}/` — карточка: производитель, БИН производителя, страна, количество в
  упаковке, источник (`source`), ссылки на фото. Публичная страница: `https://nct.gov.kz/#/products/{id}`.
* Раздел «Открытые данные» (`/opendata/api/datasets/`) требует входа. Open API НКТ и API nationalcatalog.kz (`apikey`)
  предназначены зарегистрированным участникам для подачи карточек — не использовались.
* Опубликованных лимитов нет. Конвейер делает **не больше одного запроса в секунду** (интервал между стартами запросов
  ≥ 1 с, не больше двух одновременных), замедляется при 429 и 5xx и повторяет 500 дважды с паузами 15 и 30 с.

## 3. Как искался каждый товар

`npm run photos:nct -- run` (`scripts/catalog-photos/nct-run.ts`):

1. Товары — 13 347 строк, порциями по 50 в порядке уникального `id`. Источник — снимок через публичный API сайта
   (`npm run photos -- snapshot`; при наличии `DATABASE_URL` — прямое чтение в транзакции READ ONLY). Артикул не
   используется как ключ.
2. Поиск по бренду (первое значимое слово названия): одна страница, а если всего ≤ 144 карточек — до трёх. Результат
   общий для всех товаров бренда (кэш на диске).
3. Если бренд слишком широкий — уточняющий запрос из 2–3 слов названия.
4. Если среди найденного нет карточки с тем же кодом, а артикул — валидный GTIN, отправляется проверка
   «слово + штрихкод» (до двух слов).
5. Каждая найденная карточка оценивается. До пяти лучших кандидатов сохраняются, для лидера с фото загружается полная
   карточка (производитель, БИН, количество в упаковке).
6. Контрольная точка — после каждой полной порции. Товары с неудачными запросами получают статус `error` и
   обрабатываются повторно в конце прохода и при следующем запуске.

## 4. Правила оценки (`src/lib/catalog-photos/nct-match.ts`)

| Оценка | Условие |
|---|---|
| `confirmed` | тот же GTIN (или NTIN/KZTIN, если артикул записан так); дозировка, форма, объём и фасовка из названия SALAMAT подтверждены и не противоречат; бренд из названия есть в карточке (в названии или у производителя); совпадает не меньше половины значимых слов. Штрихкод однозначно задаёт торговую единицу, то есть и вкус/аромат/версию |
| `probable` | тот же код, но часть характеристик в карточке не указана или бренд не совпал; либо найдено по названию с полным совпадением слов и подтверждёнными характеристиками |
| `doubtful` | найдено по названию, совпадает не меньше половины слов; либо «ФАСОВКА» SALAMAT (своя упаковка аптеки — фото заводской коробки ей не соответствует) |
| `mismatch` | другая дозировка, форма, объём или фасовка, а для найденных по названию — другой вариант (цвет, вкус/аромат, размер, детский/взрослый) — кандидат сохраняется, но не используется |

Дополнительно не становятся `confirmed`, даже при совпадении кода:

* **конфликт варианта** (`variant_conflict:черный≠зеленый`) — в названии SALAMAT один вариант, в карточке другой
  (чёрный/зелёный чай, детские/взрослые палочки, «травы»/«масла»). Слова одного варианта в разных формах и на двух языках
  («мята»/«мяты», «черного»/«black») конфликтом не считаются;
* **общий артикул** (`article_shared_with_N_different_products`) — в `pharmacy_products` этот артикул стоит у нескольких
  товаров с разными названиями (77 товаров), поэтому штрихкод не говорит, какой из них на карточке;
* **ассортимент** (`salamat_assortment`) — «в ассортименте» под одним артикулом: фото одного вкуса не изображает ассортимент;
* **бренд** из начала названия SALAMAT отсутствует в карточке (`brand_not_on_card`).

Разные дозировки, объёмы, фасовки, ароматы и версии считаются разными товарами. Слова названия SALAMAT, которых нет в
карточке (например, «Дыня» против «Сладкая малина»), попадают в причины `name_missing`. Производителя в таблице SALAMAT
нет, поэтому его заменяет бренд в начале названия.

**Публикация:** даже `confirmed` означает «совпадение подтверждено — нужно разрешение правообладателя». До разрешения
товар показывается без фото.

## 6. Шаблон запроса разрешения

> Тема: разрешение на использование фотографий упаковки товаров на сайте аптечной сети SALAMAT
>
> ТОО «SALAMAT FARMACIA» (БИН 160 340 015 018) ведёт интернет-витрину аптечной сети SALAMAT и просит разрешить
> неисключительное безвозмездное использование фотографий упаковки ваших товаров, размещённых вами в Национальном
> каталоге товаров (список карточек и GTIN — во вложении), на сайте SALAMAT: воспроизведение в уменьшенном размере
> (WebP/AVIF до 800 px) и доведение до всеобщего сведения в карточках этих товаров, на срок их продажи в аптеках SALAMAT.
> Просим также указать, требуется ли подпись об источнике фотографии и в какой форме.

Получив разрешение, нужно записать его реквизиты (`NCT_IMAGE_PERMISSION` или строка в `photos.csv` для отдельного
производителя), повторить обработку этих товаров, просмотреть фото и опубликовать через
`npm run photos -- publish … --confirm-rights`.
