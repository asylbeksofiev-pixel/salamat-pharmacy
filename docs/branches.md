# Филиалы, карта и геолокация

## Откуда сайт берёт адреса, телефоны и координаты

Единственный источник во время работы сайта — таблица `Pharmacy` в PostgreSQL (Neon).
Из неё берут данные список аптек, карточки, страница филиала, выбор аптеки в шапке, карта, поиск по адресу,
контакты, sitemap и блоки акций. Показываются только записи с `isActive = true`.

Исходные данные о филиалах:

| Файл | Что в нём |
| --- | --- |
| `prisma/data/branches.json` | список сети от 18.11.2026: адрес, телефон, координаты (17 филиалов) |
| `prisma/seed-data.ts` | филиалы в формате сайта (код, адрес, телефоны) и связь с `branches.json` через `branchId` |
| `prisma/migrations/20261118120000_branch_list_update/migration.sql` | то же обновление для уже работающей базы |

`prisma/seed.ts` создаёт филиалы только в пустой базе и не перезаписывает записи, изменённые в админ-панели.
Поэтому для продовой базы изменения приходят миграцией.

Миграция защищена: в пустой базе ничего не делает (там всё создаёт сид), существующую запись с тем же кодом, slug

Ничего не удаляет. Проверено на копии, воспроизводящей прод (старый сид → миграция): результат совпадает с чистым сидом,
повторный запуск дублей не создаёт.

### Как применяется

Сборка Vercel (`vercel.json`) выполняет `prisma migrate deploy` перед `next build`, поэтому миграция применяется
к продовой базе при первом деплое этого коммита. Переменные базы на Vercel общие для Production и Preview —
значит, и preview-сборка любой ветки применит миграцию к той же базе.

Вручную (если нужно применить до деплоя):

```bash
DATABASE_URL="<DATABASE_URL_UNPOOLED из Vercel>" npx prisma migrate deploy
```

## Карта

`src/components/pharmacy/PharmacyMap.tsx` — официальный виджет Яндекс Карт (`https://yandex.kz/map-widget/v1/`) во
`iframe`: API-ключ не нужен, скрипты Яндекса в сам сайт не загружаются (в CSP разрешён только `frame-src` для
yandex.kz/yandex.ru). Маркеры (`pt`) строятся из тех же записей, что и карточки; ссылки собираются в
`src/lib/yandex-maps.ts`. Виджет не поддерживает свои цвета маркеров, поэтому «Показать на карте» и ближайшая
аптека показываются центрированием карты на филиале. Пока виджет грузится — надпись «Загрузка карты…»; если он не
загрузился за 20 секунд — сообщение и ссылка «Открыть в Яндекс Картах».

Геолокация (`navigator.geolocation`) запрашивается только по кнопке «Найти ближайшую аптеку»; если посетитель уже
разрешил её сайту, ближайшая аптека находится сразу. Координаты посетителя остаются в браузере: в адрес карты они
не попадают, а в Яндекс Карты уходят только при нажатии «Построить маршрут». Расстояние — по формуле гаверсинуса
(`src/lib/geo.ts`).
