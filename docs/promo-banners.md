# Баннеры «Сервисы SALAMAT» на главной странице

Секция «Сервисы SALAMAT» идёт сразу после первого экрана главной страницы. Это **информационные** баннеры о сервисах
(аптеки рядом, заказ на сайте, справочная), а не акции: на них нет скидок, цен и сроков. Настоящие акции с условиями и
датами публикуются в админ-панели (**Акции**) и показываются отдельным блоком «Акции» на главной и на странице `/promotions`
— только пока есть опубликованные, начавшиеся и не завершённые акции. Без баннеров секция не показывается.

Баннер с `requires: "promotions"` (сейчас — «Акции SALAMAT», ведёт на страницу акций) показывается только пока есть
опубликованные акции, иначе он вёл бы на пустую страницу.

## Куда положить файлы

Папка: **`public/promo/`**. Сейчас подключены четыре баннера (16 : 9, 1672 × 941, сжаты в JPG):

| Файл | Картинка | Текст на баннере и кнопка |
| --- | --- | --- |
| `promo-1.jpg` | карта Астаны с аптеками | «Аптеки SALAMAT рядом с вами» → «Найти аптеку» (`/pharmacies`) |
| `promo-2.jpg` | зелёная карта, монеты, подарок | «Акции SALAMAT» → «Смотреть акции» (`/promotions`) |
| `promo-3.jpg` | пакет, смартфон, товары | «Закажите на сайте — заберите в аптеке» → «Открыть каталог» (`/catalog`) |
| `promo-4.jpg` | фармацевт с планшетом | «Фармацевт подскажет» → «Вопросы и ответы» (`/help`) |

Следующий баннер — `promo-5.jpg` и т. д.

* Пропорции **16 : 9**, рекомендуемый размер **2560 × 1440 px** (чем крупнее исходник, тем резче баннер на больших и Retina-экранах), JPG/PNG/WebP, до ~400 КБ.
* На телефонах и планшетах баннер показывается целиком (16 : 9), на широких экранах (от 1024 px) — в рамке 2 : 1,
  поэтому сверху и снизу срезается примерно по 5 % высоты: важный текст держите дальше от этих краёв.
* Можно указать отдельную картинку для телефона (`mobile`), тоже 16 : 9.
* Сайт сам уменьшает изображения под экран (next/image), но не увеличивает: файл уже 1600 px будет мягче на
  больших экранах.

## Как подключить

Файл **`src/config/promo-banners.ts`**, массив `PROMO_BANNERS`. Раскомментируйте пример и заполните:

```ts
export const PROMO_BANNERS: PromoBanner[] = [
  {
    id: "promo-3",
    desktop: "/promo/promo-3.jpg",
    mobile: "/promo/promo-3.jpg",
    alt: {
      ru: "Текст, написанный на баннере",
      kk: "Баннерде жазылған мәтін",
      en: "The text written on the banner",
    },
    href: "/pharmacies", // необязательно; путь сайта или https://…
    // requires: "promotions", // только если баннер ведёт на страницу акций
  },
];
```

* `alt` обязателен на трёх языках и должен повторять текст, написанный на картинке (для незрячих посетителей и
  поисковиков).
* Если на баннере текст на одном языке, а нужны разные версии, вместо строки укажите объект:
  `desktop: { ru: "/promo/promo-3-ru.jpg", kk: "/promo/promo-3-kk.jpg", en: "/promo/promo-3-en.jpg" }`.
* `href` — путь сайта без языкового префикса (`/promotions/...`): `/kk` или `/en` добавятся сами.
* Порядок в массиве = порядок слайдов.
* `caption` (необязательно) — заголовок, короткий текст и кнопка поверх пустой левой части картинки (на телефоне —
  под ней), на трёх языках; кнопка ведёт на `href`, по баннеру тоже можно нажать. Только реальная информация:
  без выдуманных скидок, цен и сроков. Без `caption` баннер — просто картинка-ссылка (текст должен быть на самой картинке).

`npm test` проверяет, что каждый указанный файл существует, `id` уникальны, а `alt` заполнен на всех языках.
После коммита и push баннеры появятся с ближайшим деплоем.

## Как работает карусель

* один баннер на экране; свайп на телефоне (нативная прокрутка со snap), перетаскивание мышью на компьютере;
* кнопки «назад / вперёд» и точки-индикаторы (текущий слайд отмечен `aria-current`); стрелки ←/→, Home/End на
  элементах управления;
* автопрокрутки нет — баннер меняется только по действию посетителя (поэтому и останавливать нечего: ничего не движется
  само); при `prefers-reduced-motion` переход мгновенный;
* при одном баннере стрелки и точки не показываются.
