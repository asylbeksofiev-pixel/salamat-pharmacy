# Дизайн-система SALAMAT

Токены определены в `src/app/globals.css` (блок `@theme` Tailwind CSS 4) и доступны как утилиты: `bg-brand-600`,
`text-ink`, `rounded-[var(--radius-lg)]` и т. д.

## Цвета

Логотип взят с официального сайта (`public/brand/salamat-logo.png`, PNG 1450×366). Цвета сняты с пикселей файла;
это не утверждённые HEX-коды брендбука — их нужно подтвердить у SALAMAT.

| Токен | HEX | Источник | Применение |
|---|---|---|---|
| `brand-500` | `#009846` | зелёный логотипа | крупная графика, знак, декоративные элементы |
| `brand-600` | `#007A3D` | затемнённый `brand-500` | основные кнопки, ссылки, фокус. Белый текст 5,45:1 |
| `brand-700` | `#00662F` | | hover основных кнопок |
| `brand-800` | `#245B2C` | тёмно-зелёный со старого сайта | блок «О сети», тёмные акценты. Белый текст 8,05:1 |
| `brand-50/100/200/300` | `#EEF8F1` … `#7CCB98` | подобраны | фоны, выбранные состояния |
| `accent-500` | `#E31E24` | красный логотипа | ограниченно: счётчик корзины, метка акции, точка-маркер |
| `accent-600/700` | `#C8161D` / `#A3121A` | | текст ошибок и критичных состояний (5,85:1 на белом) |
| `ink` | `#14231A` | | основной текст (16,3:1) |
| `ink-soft` / `muted` | `#33443A` / `#56645B` | | второстепенный текст (muted: 6,2:1 на белом) |
| `line` / `line-strong` | `#E1E8E3` / `#C9D4CC` | | границы |
| `surface` | `#F4F7F5` | | фон секций |
| `warn-50/700` | `#FFF6E0` / `#8A5A00` | | «требует подтверждения», демо-баннер (5,5:1) |
| `info-50/700` | `#EAF2FB` / `#1F5A96` | | информационные плашки, бонусы |

Почему не `#009846` для кнопок: белый текст на нём даёт 3,76:1 — ниже WCAG AA для обычного текста.

Состояние никогда не передаётся только цветом: наличие — иконка + текст («✓ Есть в наличии», «! Осталось мало»,
«× Нет в наличии», «? Наличие уточняется», «⏱ Наличие требует подтверждения»), рецептурность — значок с текстом.

## Типографика

* Шрифт: **Onest Variable** (`@fontsource-variable/onest`, OFL, раздаётся с собственного домена).
  Проверено fontTools: в подмножестве cyrillic-ext есть все казахские буквы ә ғ қ ң ө ұ ү һ і и прописные.
  Manrope отклонён — в нём нет ә ғ қ ң ұ.
* Шкала: H1 hero 34–54 px (extrabold, межбуквенный −0.01em), H1 страниц 28–36 px, H2 секций 24–28 px,
  основной текст 16–17 px, вспомогательный 13–14 px. Минимальный размер интерактивного текста — 14 px.
* Длина строки в текстовых страницах ограничена 70 знаками (`.prose-salamat`).

## Сетка, отступы, радиусы, тени

* Контейнер `container-page`: максимум 1320 px, поля 16/24/32 px.
* Радиусы: 6, 10, 14, 20, 28 px (`--radius-sm` … `--radius-2xl`). Карточки — 20 px, кнопки и поля — 10 px.
* Тени: `--shadow-card` (лёгкая, для карточек при hover), `--shadow-pop` (меню, модальные окна).
* Брейкпоинты Tailwind: `sm` 640, `md` 768, `lg` 1024, `xl` 1280. Проверено на 320, 375, 768, 1024, 1440 px —
  горизонтальной прокрутки нет.

## Иконки и изображения

* Собственный набор линейных иконок 24 px (`src/components/icons.tsx`), включая значки девяти категорий.
* Товары без разрешённого фото показывают нейтральную заглушку «Фото уточняется».
* Иллюстрация «провизор» со старого сайта не используется (происхождение и права неизвестны, клишированный образ).
* Hero собран из знака логотипа и интерфейсных карточек, без стоковых фото.

## Правила текста и состояний

* Цена не может быть «0 ₸»: отсутствующая цена — «Цена уточняется».
* Неизвестный остаток не может быть «Есть в наличии».
* Бонус — отдельный голубой значок «Бонус 300 ₸», никогда не в блоке цены.
* «Прежняя цена» зачёркнута только рядом с подтверждённой свежей ценой и только если она выше текущей.
* Заявка ≠ заказ: «Заявка отправлена, оператор подтвердит детали».
* Медицинских советов нет; на карточке товара — предупреждение об инструкции и консультации специалиста.

## Движение

* **Смена страниц** — React `<ViewTransition default="page">` в макетах сайта и админки (View Transitions API):
  старая страница гаснет за 140 мс, новая проявляется и поднимается на 10 px за 260 мс. Шапка, нижняя панель
  и боковое меню админки не анимируются (`viewTransitionName`). Работает и при смене фильтров, варианта товара,
  аптеки. В браузерах без поддержки View Transitions страницы просто меняются сразу.
* **Окна и шторки** (`ui/Dialog.tsx`) — модальное окно всплывает, шторки выезжают со своего края, фон плавно
  затемняется; при закрытии (кнопка, Escape, клик по фону) играет обратная анимация, содержимое остаётся до её конца.
* **Выпадающие списки** (каталог, подсказки поиска) — `anim-pop`, уведомления — `anim-toast`.
* **Аккордеоны** `<details>` (FAQ, админка) раскрываются плавно там, где браузер поддерживает `::details-content`.
* **Прокрутка** к якорям — плавная (`data-scroll-behavior="smooth"`); при переходах между страницами Next.js её отключает.
* Взаимодействия — 150–200 мс, только цвет/тень/transform/opacity (`--ease-out-soft`).
* `prefers-reduced-motion: reduce` отключает все анимации, включая переходы страниц.
