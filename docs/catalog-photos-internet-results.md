## Обновление: публикация прямыми ссылками (2026-11-19, вечер)

По решению владельца фото публикуются так же, как фото NCT: исходной ссылкой в `image_url`, без Vercel Blob.

- Проверено 576 одобренных фото (77 confirmed + 499 probable; 181 отклонённое исключено). Все 576 исходных ссылок
  открываются без авторизации, отдают `image/jpeg`, CORS `*`, без `Cross-Origin-Resource-Policy`, и после той же
  обработки дают тот же SHA-256, что просмотренный файл: изменившихся 0, недоступных 0. В браузере со страницы
  сайта загрузились 40 из 40 случайных ссылок.
- Оригиналы большие (медиана 3 773 px и 614 КБ, 150 файлов больше 1 МБ, всего 414 МБ), поэтому сайт отдаёт их через
  next/image (уменьшенные копии).
- Подготовлены CSV и SQL для psql: `data/catalog-photos-internet/neon-import/`. Проверено на копии таблицы из 13 347
  строк: 576 записано, повторный запуск блокируется, откат возвращает 576, ручные изменения после импорта не
  трогаются, товары с изменённым названием или уже заполненным `image_url` пропускаются.
- **В production Neon ещё ничего не записано**: импорт выполняет владелец после деплоя.

Прямые SQL-подсчёты выполнить не удалось: нет доступа к базе. Владелец может сверить цифры:

```sql
SELECT count(*) AS total,
       count(*) FILTER (WHERE NULLIF(BTRIM(image_url), '') IS NOT NULL) AS with_image,
       count(*) FILTER (WHERE NULLIF(BTRIM(image_url), '') IS NULL)     AS without_image
FROM public.pharmacy_products;
```

API отдаёт фото только для `https://`-ссылок. Если в колонке есть непустые не-https значения, SQL покажет чуть
меньше товаров без фото. На результат это не влияет: публикация перепроверяет `image_url` каждого товара
перед записью.

`public.catalog_photo_candidates_import` в коде и миграциях не встречается; структура таблицы неизвестна, конвейер
её не использует и не меняет.

## Контроль качества

**Все 85 confirmed просмотрены** (`data/catalog-photos-internet/qa-decisions.csv`).

- Товар определён верно в 85 из 85 случаев: тот же продукт, объём и вариант.
- Фото непригодно в 8 случаях — **отклонены**:
  - 1006 Weleda гель для душа — обратная сторона (состав);
  - 1756 Bioderma Hydrabio H2O — обратная сторона флакона;
  - 6060 Nivea Care крем — товар занимает малую часть кадра;
  - 6180 Biorepair — на фото листок-инструкция, не упаковка;
  - 6636 CeraVe лосьон — товар мал в кадре;
  - 8079 Mustela молочко SPF50+ — обратная/боковая сторона;
  - 9293 Avène лосьон — упаковка нечитаема;
  - 11105 Teen Derm гель — крупный план штрихкода.
- Точность сопоставления confirmed — 100 % (85/85); пригодность фото — 90,6 % (77/85).

Ошибки в confirmed касались качества снимка, а не сопоставления. Поэтому правила ужесточены:

1. штрихкод на фото (ZXing): крупный план штрихкода или штрихкод другого товара → probable;
2. обратную сторону упаковки и мелкий товар в кадре автоматически не отличить, поэтому `photos:publish` по
   умолчанию публикует только одобренные фото. Автоматическая публикация confirmed без просмотра включается только
   явным флагом `--allow-unreviewed`.

Одобрение 77 фото — результат визуальной проверки в этой сессии (`reviewer` в CSV), а не проверка сотрудником
SALAMAT. Владелец может пересмотреть `confirmed_photos.csv` перед публикацией.

**Выборка из 50 probable** (`qa-sample-probable.csv`, все разделы, где есть кандидаты):

- товар верный — 47, неверный — 2, нельзя определить — 1 (точность сопоставления 94–96 %):
  - 4256 «Бинт гипсовый Фармадел» — в Open Food Facts под этим штрихкодом фото пакета муки (ошибка в базе);
  - 7180 «Uriage Hyséac крем 3-Regul» — на фото флюид Hyséac SPF50+;
  - 7998 Solgar витамин C — на фото только текст состава;
- фото пригодно — 42 из 50 (84 %); непригодные (обратная сторона, штрихкод, состав, посторонний предмет) отклонены.

Вывод: probable нельзя публиковать без просмотра. Примерно каждое шестое фото в этой группе непригодно, каждое
двадцать пятое — другой товар.

## Хранилище и стоимость

Файлы лежат локально в `.photo-work/internet/files/` (757 файлов, 115 МБ, в Git не попадают). После публикации
они окажутся в Vercel Blob по пути `products/{product_id}/{sha256}.{ext}`.

| Объём | Файлов | Размер | Blob, Hobby | Blob, Pro (iad1) |
|---|---:|---:|---|---|
| Готово к публикации | 576 | 85,6 МБ | в бесплатном лимите (1 ГБ, 2 000 загрузок) | ≈ $0,002/мес хранение + $0,003 загрузки |

Трафик из Blob: посетители получают уменьшенные копии от оптимизатора next/image, а он скачивает оригинал из Blob
и кэширует его. 10 ГБ бесплатного трафика — это около 65 000 скачиваний оригинала (в среднем 150 КБ) в месяц.

## Что осталось владельцу

Подробная пошаговая инструкция — в описании PR и в [catalog-photos-internet.md](catalog-photos-internet.md#настройка-один-раз-владелец-проекта-vercel).
Коротко:

1. **Дать доступ или выполнить публикацию самому.** Либо пригласить аккаунт Vercel, подключённый к Claude, в
   команду `zhd-dzh` (Team Settings → Members → Invite), и тогда Claude выполнит шаги 2–5; либо выполнить их на
   своей машине.
2. Vercel → `zhd-dzh/salamat-pharmacy` → Storage → Create Database → Blob → создать публичное хранилище →
   Connect Project (Production, Preview). Появится `BLOB_READ_WRITE_TOKEN`.
3. Смёрджить PR — production-сборка применит миграцию (две новые таблицы).
4. На своей машине: `vercel env pull .env.local`, повторить поиск и проверку (`photos:snapshot`,
   `photos:fetch-sources`, `photos:discover`, `photos:validate`), применить решения из двух CSV, затем
   `photos:publish -- --dry-run`, `--confirm --limit 10`, проверить 10 карточек, опубликовать остальные.
5. Чтобы закрыть остальные ~8 500 товаров, нужны фото с правом использования:
   - запросить фото у поставщиков SALAMAT и производителей (больше всего товаров без фото: Медтекстиль 158,
     Canpol 139, Бусинка 138, Philips Avent 115, Эвалар 112, Тонус Эласт 110, Avène 106, La Roche-Posay 104,
     Vichy 100, Bioderma 98, NUK 93, R.O.C.S. 88, Orlex 85, Mirrolla 84, Omron 84, Splat 83, Bella 82, Curaprox 82);
     файлы с письменным разрешением загружаются тем же конвейером (`rights_status = permission_granted`);
   - разрешение владельцев карточек НКТ (подробности в ветке `claude/jolly-dirac-tpd3xo`);
   - собственная съёмка товаров в аптеках SALAMAT.
