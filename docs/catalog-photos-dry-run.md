# Фото товаров — пробный прогон (dry run)

Дата: 18.11.2026. Команда:

```bash
npm run photos -- process --site-api https://salamat-pharmacy.vercel.app --ids-file ids.txt
```

40 товаров production (`public.pharmacy_products`) прочитаны через публичный API сайта, только чтение. Выборка
специально разнородная: лекарства (таблетки, капсулы, растворы, порошки), БАД (NOW, UPC-A), витамины, детские товары,
косметика, продукты, медизделия и все проблемные виды артикулов — внутренние коды магазина, неверная контрольная цифра,
нецифровой артикул, EAN-8, GTIN-14. Ничего не загружено в Blob и не записано в Neon. Продолжительность — около 2 минут
(Open Food Facts отвечал 429 при паузе 0,9 с; после повторов все запросы прошли, пауза увеличена до 2,5 с с
автоматическим замедлением).

## Оценка для всего каталога (13 347 товаров)

Выборка мала и неслучайна, поэтому оценка грубая:

* **без новых разрешений**: подтверждённых автоматически — около 0–2 %; кандидаты Open Food Facts на проверку — около 15 %
  (≈ 2 000 товаров, после просмотра часть можно утвердить); карточки НКТ, которые ждут разрешения, — около 65 % (≈ 8 700);
  без кандидата — около 20 % (≈ 2 700);
* **с файлами от SALAMAT или производителей** доля подтверждённых растёт пропорционально присланным файлам: привязка к
  `product_id` принимается автоматически;
* стоимость и время — `docs/catalog-photos.md`, раздел 10: при Pro меньше $1 за загрузку и хранение всего набора,
  9–10 часов на полный прогон с паузами.
