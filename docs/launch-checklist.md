# Чек-лист запуска

Статус на 14.11.2026. Сайт технически готов к наполнению и приёмке, но **не готов к продажам**: нет ассортимента,
цен, остатков, утверждённых юридических документов и подтверждённых контактов.

## 1. Данные от SALAMAT

| Что | Статус | Как загрузить |
|---|---|---|
| Ассортимент (SKU, штрихкоды, формы, дозировки, категории) | ❌ нет | Выгрузка из учётной системы → `/admin/import` (`docs/data-import.md`) |
| Цены по филиалам с датой актуальности | ❌ нет | та же выгрузка или API; вручную — «Цены и остатки» |
| Остатки по филиалам | ❌ нет | та же выгрузка или API |
| Рецептурный статус SKU | ❌ нет | колонка `prescription_status` |
| Фото товаров (с правом использования) | ❌ нет | колонка `image_url`, хосты — в `IMAGE_HOSTS` |
| Подтверждение 14 адресов и телефонов | ⚠️ с прежнего сайта (апрель 2025) | «Филиалы» → отметка «Сведения проверены сегодня» |
| Часы работы филиалов | ❌ нет | «Филиалы» → график + «График подтверждён» |
| Координаты филиалов | ❌ нет | «Филиалы» → широта/долгота (появится карта) |
| Населённый пункт филиала в с. Ильинка | ⚠️ расхождение | уточнить, к какому городу относить |
| Справочный телефон и часы справочной | ⚠️ 8 (701) 672 76 27 с прежнего сайта; в политике другой номер (762) | «Настройки» |
| Официальный e-mail, лицензия на фармдеятельность, сертификаты GPP | ❌ нет | «Настройки» → Компания |
| Казахские названия категорий и переводы интерфейса | ⚠️ сделаны в проекте | проверка носителем языка (`src/lib/i18n/kk.ts`, категории в админке) |
| Казахские адреса филиалов | ❌ не создавались | «Филиалы» → «Адрес (KZ)» |
| Покупательские акции | ❌ нет (Pharmapay — кэшбэк для аптек, не для покупателей) | «Акции» |
| Логотип в векторе, брендбук (HEX-коды) | ❌ используется PNG с сайта | заменить `public/brand/*`, уточнить токены |

## 2. Решения владельца

* Разрешить ли онлайн-заявки на рецептурные препараты (сейчас запрещены, `rxPolicy=BLOCK`) — после проверки
  требований законодательства РК юристом.
* Политика для SKU с неподтверждённой рецептурностью (сейчас — разрешено с пометкой).
* Пороги устаревания цены (72 ч) и остатка (24 ч).
* Доставка: зоны, стоимость, сроки, способы оплаты (в политике старого сайта упоминается доставка с предоплатой и
  WhatsApp-бот) — до решения доставка выключена.
* Кто из сотрудников получает какие роли и филиалы.
* Срок хранения контактов в заявках (по умолчанию 180 дней).

## 3. Юридические документы

* `/privacy` и `/terms` — черновики с пометкой «требует юридической проверки», не индексируются. Юрист должен
  утвердить текст, затем снять пометку в «Страницы и FAQ» и обновить «Версию политики для согласия» в настройках.
* Публичная оферта и правила возврата — при подключении оплаты/доставки.

## 4. Внешние доступы для production

| Что | Зачем | Переменные |
|---|---|---|
| PostgreSQL 16 (managed, с бэкапами) | данные | `DATABASE_URL` |
| Хостинг Vercel (или Node.js-сервер) | сайт | — |
| Домен и HTTPS | `APP_URL`, canonical, cookie Secure | `APP_URL` |
| Секреты | хеширование IP, cron | `APP_SECRET`, `CRON_SECRET` |
| SMTP (почтовый сервис) | уведомления операторам | `SMTP_*`, `OPERATOR_EMAILS` |
| SMS / WhatsApp Business | уведомления покупателям — не реализовано, нужен провайдер | — |
| API учётной системы SALAMAT | автоматическая синхронизация | `CATALOG_API_URL`, `CATALOG_API_TOKEN` |
| CDN изображений | фото товаров | `IMAGE_HOSTS` |
| Картографический сервис | карта всех аптек (сейчас: виджет Яндекс Карт без ключа на /pharmacies и странице филиала, ссылки на маршрут в Яндекс Картах; для подсказок и геокодера Яндекса — `YANDEX_SUGGEST_API_KEY`, `YANDEX_GEOCODER_API_KEY`) | — |
| Платёжный провайдер | онлайн-оплата — не подключена | реализовать `src/server/payments/provider.ts` |
